# Smart Attendance System Using RFID

## 📌 Project Description

The Smart Attendance System using RFID is an IoT-based attendance management system that automatically records the attendance of students using RFID technology.

Each student is provided with a unique RFID card. When the card is scanned by the RFID reader, the system identifies the student and records their attendance.

## 🎯 Objectives

- Automate the attendance process.
- Reduce manual attendance work.
- Minimize errors in attendance records.
- Identify students using unique RFID cards.
- Provide a simple and efficient attendance system.

## 🛠️ Components Used

### Hardware
- NodeMCU (ESP8266)
- RC522 RFID Reader
- RFID Cards/Tags
- LCD Display
- Buzzer
- LEDs
- Jumper Wires
- Breadboard
- USB Cable

### Software
- Arduino IDE
- Embedded C/C++
- ESP8266 Board Package

## ⚙️ Working

1. The system is powered using the NodeMCU.
2. The RFID reader continuously checks for an RFID card.
3. When a card is placed near the reader, its unique ID is detected.
4. The NodeMCU processes the RFID ID.
5. The system verifies the student information.
6. Attendance is recorded.
7. The LCD displays the attendance/status message.
8. A buzzer or LED provides confirmation.

## 🔄 System Flow

RFID Card → RC522 RFID Reader → NodeMCU ESP8266 → Student Identification → Attendance Recorded
